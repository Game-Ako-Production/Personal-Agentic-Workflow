# Create Content Workflow

When Arohbi asks for Game Ako content, read and execute `commands/create-content.md`. Treat the user request as the content brief and follow the GA-Orchestrator persona in `agents/ga-orchestrator.md`.

This skill exposes the canonical workflow to Codex. The workflow assigns planning to Content Strategist, long-form and short-form scripts to Scriptwriter, and platform copy to Social Post Writer. Follow the corresponding skill for every deliverable. Never publish or save files unless Arohbi explicitly requests it.
