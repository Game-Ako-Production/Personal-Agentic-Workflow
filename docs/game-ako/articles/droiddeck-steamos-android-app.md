DroidDeck is not a new handheld — it's free software that makes the Android device you already own feel like a Steam Deck. The open-source app (from the Droid-Deck GitHub org, GPL-3.0, no Valve affiliation) runs Valve's official ARM64 Steam client in Big Picture mode and plays Windows PC games via ARM64 Proton plus FEX, with no root required, per Android Authority and VideoCardz.

**Three releases in two weeks**

DroidDeck went public in late September 2026, and coverage exploded between October 3 and 6 from Retro Game Corps, Android Authority, VideoCardz, and The Verge. The release cadence has been fast: v0.3.0 added Steam Deck controller emulation, Quick Access, gyro support, Steam Input, LSFG frame generation, and faster Steam startup. Then v0.4.0, out October 12, adds a KDE Plasma SteamOS-style desktop, GOG, Epic, and Amazon integration, four-controller local co-op, foldable support, and DroidDeck-Proton.

**What you need**

Requirements: Android 9 or newer with an Adreno 730 or newer GPU, or 8xx-series GPUs. Adreno 6xx is experimental; Mali, Xclipse, PowerVR, and Adreno 710 are unsupported. Expect around 3 GB of runtime storage, plus an optional ~1.1 GB desktop component. It's beta-quality, so bugs are common and heavy games can struggle. One user observed MXGP 2021 climbing from roughly 20 to 60 fps on an Odin 3 after 0.3.0 — a single observation, not a benchmark.

**The Philippine angle — and a safety warning**

That buzz matters locally because many Filipino handheld enthusiasts import Snapdragon 8 Gen 2-and-up devices such as Odin, Retroid, and AYN — though no sourced PH pricing or official local availability has been verified, so we won't guess prices here. Whatever you do, download only from GitHub Releases: the README warns there is no standalone website, and fake download sites exist.
