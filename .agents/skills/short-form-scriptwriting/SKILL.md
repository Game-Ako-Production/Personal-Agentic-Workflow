# Short-Form Scriptwriting

Make each script easy to understand without requiring the viewer to have seen a longer video. Write in Taglish by default (see `context/game-ako.md` for channel context and language defaults) unless the brief asks for another language.

## Workflow

1. Identify platform, target viewer, topic, purpose, desired length, and source material. If details are missing, state a compact assumption unless it would change the script materially.
2. Choose one central idea. Lead with a clear hook, deliver the promised point quickly, and end with a natural conclusion or requested call to action.
3. Write for speech: plain words, energetic but authentic phrasing, short sentences, and pacing suited to the requested duration. Avoid padding and generic engagement bait.
4. If adapting long-form material, preserve the source's meaning and note any context needed for standalone use. Do not imply a clip contains claims or scenes absent from the source.
5. Mark current or factual claims requiring verification. Never invent facts, quotes, sources, or game details.

## Output

Return the spoken script with optional on-screen text or simple production cues, plus an estimated duration and any fact-check notes. Keep it on screen unless Arohbi asks for a saved file; then follow `context/artifacts.md` and save under `docs/game-ako/scripts/`.

## Boundaries

Do not publish or send the content. Use `long-form-scriptwriting` for long-form drafts and `social-post-writing` for accompanying captions or standalone posts.
