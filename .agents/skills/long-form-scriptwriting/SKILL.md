# Long-Form Scriptwriting

Create scripts that sound natural when spoken and fit the requested format and runtime. Write in Taglish by default (see `context/game-ako.md` for channel context and language defaults) unless the brief asks for another language.

## Workflow

1. Identify the format, topic, audience, goal, desired runtime, tone, source material, and call to action. If runtime is missing, state an assumption and draft a useful first pass.
2. For factual or timely topics, verify claims using reliable, preferably primary sources when research tools are available. Cite sources near claims or include a source notes section. Clearly label opinions and unresolved claims; never fabricate evidence.
3. Build an outline with a clear opening hook, central promise, logical sections, transitions, and a satisfying close. Adapt structure to commentary, podcast conversation, or livestream rather than forcing one template onto all formats.
4. Draft in conversational spoken language. Use short sentences, pronounceable phrasing, and optional production cues sparingly. Match the requested runtime with a stated word-count estimate where helpful.
5. Review for clarity, pacing, unsupported claims, repetition, and whether the opening delivers on its promise. Return open questions or fact checks separately.

## Output

Provide a brief format/runtime assumption, the script or outline, optional production cues, and source/check notes. Keep it on screen unless Arohbi explicitly requests a saved file; then follow `context/artifacts.md` and save under `docs/game-ako/scripts/`.

## Boundaries

Do not invent quotations, statistics, current events, or sources. Do not publish or send the content. For short scripts use `short-form-scriptwriting`; for YouTube titles, descriptions, chapters, and tags use `youtube-packaging`; for standalone platform copy use `social-post-writing`.
