# Game Ako YouTube conventions

YouTube-specific channel conventions. Core channel facts (platform roles, audience, pillars, coverage scope, language defaults, voice, publication boundary) are in `context/game-ako.md`; blog conventions are in `context/game-ako-blog.md`.

- Game Ako Speaks! commentary videos use the suffix ` | GameAko Speaks!` (brand written as one word in titles).
- Do not apply that suffix to NewsKoPo, GALore, or other series. Use a known series convention only; otherwise omit the suffix unless Arohbi requests one.
- Past titles that set the style:
  - `Physint Goes to Xbox & Wolverine's Review Drama is Not What You Think | GameAko Speaks!`
  - `Physint: The Risk Behind Funding Creative Games | GameAko Speaks!`

## Language

- Use English for titles, thumbnail text, descriptions, chapters, and tags by default, following `context/game-ako.md`.
- Use Taglish or another language only when Arohbi explicitly requests it.

## Standard description block

Append this block, exactly as written, to every long-form YouTube description. Replace the placeholders once Arohbi supplies the details, then remove this sentence.

```text
[PLACEHOLDER: channel subscribe link]

[PLACEHOLDER: standard disclaimer, if any]
```
