# CAPCOM’s RE Engine AI Plans Take Shape Through REX

**Draft type:** Short news update  
**Audience:** Filipino gamers  
**Prepared:** October 6, 2026  
**Primary source:** [Wccftech](https://wccftech.com/capcom-rex-engine-ai-generation/)

CAPCOM is preparing its RE Engine for an “AI generation,” but its current plans focus on development tools—not AI-generated game content. According to [Wccftech’s report on programmer Satoshi Ishida’s presentation](https://wccftech.com/capcom-rex-engine-ai-generation/), REX is an evolution of the RE Engine designed to make the technology easier for developers—and AI—to work with.

## What REX means for RE Engine AI

Ishida discussed REX at CAPCOM Open Conference RE:2026 on Oct. 2. It is not a wholly new engine, Wccftech reports. Instead, the initiative aims to standardize the engine’s code around a common programming language, making it easier to read and work with.

CAPCOM’s stated future vision includes using AI to help write code, run test playthroughs, and find bugs. The presentation also covered development tools for tasks such as managing logs, translation, and quality assurance.

## Development tools, not AI-made game content

That distinction matters: Wccftech’s report describes tools intended to support game development. It does not say REX will use AI to generate art, assets, or in-game content.

REX is also intended to address longer iteration times as games grow, improve usability for CAPCOM’s more than 2,000 developers, and help with the challenges of multilingual teams. The initiative is being introduced incrementally through technologies including RE:Dox, RE:UI, RE:Log, RE:Flows, and RE:Runtime.

## No rollout details yet

The report does not give a rollout schedule or identify which games will first use these technologies. So while REX points to CAPCOM’s plans for AI-assisted development, it is too early to say what players will notice—or when.

For now, REX is about changing how games could be made behind the scenes, not confirming AI-generated content in upcoming releases.
